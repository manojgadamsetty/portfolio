# Portfolio v3

Portfolio v3 is an original, static, cinematic portfolio experience inspired by
streaming-platform storytelling. It is kept separate from the live v2 entry
point while the design and content are being reviewed.

## Preview locally

Open [`index.html`](./index.html) directly, or serve the repository root:

```bash
npm start
```

Then visit `/v3/`.

## Contents

- `index.html` — intro sequence, portfolio sections, and project dialog markup
- `styles.css` — responsive visual system and streaming-style layout
- `app.js` — intro state and project detail interactions

The page uses portfolio content from the current Idira and CyberArk experience.
The root `index.html` remains connected to v2 until v3 is approved for
promotion.
